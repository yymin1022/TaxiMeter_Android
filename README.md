## Get Started

1. Clone this repository on your local environment
   ```bash
   yong@ubuntu-server ~/ :$ git clone https://github.com/yymin1022/TaxiMeter_Android.git
   ```
3. Build with gradle, and install to your own device
   ```bash
   yong@ubuntu-server ~/ :$ cd TaxiMeter_Android
   yong@ubuntu-server ~/TaxiMeter_Android/ :$ ./gradlew assembleDebug
   yong@ubuntu-server ~/TaxiMeter_Android/ :$ adb install app/build/outputs/apk/app-debug.apk
   ```
